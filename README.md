# Site MS Bat

Site vitrine : plomberie, chauffage, électricité et dépannage en Île-de-France.

## Fichiers
- `index.html` – la page du site
- `style.css` – les couleurs et la mise en page
- `script.js` – menu mobile, animations, vérification du formulaire
- `mentions-legales.html` – page obligatoire

## Mettre le site en ligne sur GitHub Pages
1. Créez un compte sur github.com.
2. Cliquez sur **New repository**, nommez-le par exemple `msbat`, cochez **Public**, puis **Create repository**.
3. Cliquez sur **uploading an existing file** et glissez tous les fichiers du dossier.
4. Cliquez sur **Commit changes**.
5. Allez dans **Settings → Pages**. Dans « Branch », choisissez `main` et `/ (root)`, puis **Save**.
6. Après 1 à 2 minutes, le site est en ligne à l'adresse : `https://VOTRE-PSEUDO.github.io/msbat/`

## Formulaire de devis
Le formulaire passe par FormSubmit (gratuit). **La toute première demande envoyée** déclenche un e-mail de confirmation sur moucheikh4@gmail.com : cliquez sur le lien pour l'activer. Ensuite, toutes les demandes arrivent directement dans votre boîte mail.

## Modifier quelque chose
- Téléphone, adresse, services : dans `index.html`
- Couleurs : en haut de `style.css` (section `:root`)

## Nom de domaine (optionnel)
Achetez par exemple `msbat.fr` (environ 10 €/an), puis renseignez-le dans **Settings → Pages → Custom domain**.
